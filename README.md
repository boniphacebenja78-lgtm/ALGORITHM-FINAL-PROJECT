# ALGORITHM-FINAL-PROJECT

## Setup

Requires Python 3.13.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Run

```powershell
python SKYLINE.py
```

The script runs the skyline benchmarks and saves the comparison chart as
`skyline_benchmark.png`.
